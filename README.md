### **Segunda parte:**<br>
Desafio Final — Análise de Dados de Energia com API Pública<br>
Situação-problema:<br>
Uma equipe de planejamento energético precisa analisar o comportamento da carga elétrica de uma região atendida pelo Sistema Interligado Nacional (SIN).
Os dados serão obtidos diretamente de uma API pública do Operador Nacional do Sistema Elétrico (ONS). A conexão com a API e a preparação inicial do JSON já estão fornecidas. A partir daí, sua equipe deverá construir o DataFrame, organizar os dados, criar recortes, calcular indicadores, produzir gráficos e elaborar um relatório técnico.<br>

Fonte dos dados<br>
API pública de Carga Verificada do ONS<br>
Portal: https://dados.ons.org.br/<br>
Conjunto de dados: https://dados.ons.org.br/dataset/carga-energia-verificada
